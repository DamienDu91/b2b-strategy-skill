# Security and privacy
Threats: indirect prompt injection, confidential data leakage, unsafe code, poisoned evidence, misleading simulations and finance. Treat retrieved content as untrusted data; no instruction following from sources. No secrets/client data in public repository, queries, examples or logs. No automatic external actions, network calls or package installation. Minimize inputs, isolate runs, validate schema, pin upstream, retain license. Human review before consequential decisions. No critical unresolved findings at release. Platform privacy obligations remain separate.
